    New galaxy

    Players with the same team letter start the game as allies (they can station ships on each other's worlds and fight together). Alliances can change at any time from the Diplomacy window. Everyone starts on a home world (a spawn point) with 20,000 credits; the other worlds are held by militia.

    Starting a new galaxy replaces the game in progress.

    Diplomacy

    Who is allied with whom

    Allies can station ships on each other's worlds, defend them together and join each other's attacks. Everyone else is an enemy. An alliance needs both players to agree; either one can break it, which sends their ships on each other's worlds home.
